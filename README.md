# Deadlock Match Win Probability Predictor

My first machine learning project, built to predict the winner of a live Deadlock match using player statistics, selected heroes, and previous match performance.

The project covers the full ML pipeline: collecting match data, building the dataset, selecting features and model parameters, training Logistic Regression and Random Forest models, and using them for live match predictions.

The current models achieve around 60% accuracy on the held-out test data and return both the predicted winner and win probability for each team.
